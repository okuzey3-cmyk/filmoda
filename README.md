# Filmoda

Ruh haline, vaktine ve kiminle izleyeceğine göre bu akşam için üç film öneren uygulama.

Film verisi ve görselleri TMDB'den gelir. Bu uygulama TMDB API'sini kullanır, ancak TMDB tarafından onaylanmamış veya sertifikalandırılmamıştır. Yayın platformu bilgisi JustWatch tarafından sağlanır.
